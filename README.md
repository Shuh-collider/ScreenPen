# ScreenPen

Рисование поверх экрана, скриншоты и длинные скриншоты с прокруткой для Windows.
Портативная программа: один `ScreenPen.exe` (около 230 КБ), установка не нужна.

**Скачать:** [последний релиз](https://github.com/Shuh-collider/ScreenPen/releases/latest) — архив `ScreenPen-Portable`, распакуйте в любую папку и запустите `ScreenPen.exe`.

## Возможности

- **Рисование поверх любых окон:** кисть, стрелка, линия, прямоугольник, овал, текст.
- **10 цветов и 3 толщины.** Линии гладкие, с лёгкой тенью, хорошо видны на любом фоне.
- **Отмена и очистка** рисунка.
- **Скрыть / показать рисунки** (кнопка-глаз): рисунки прячутся, но не удаляются.
- **Затемнение экрана**, чтобы рисунок был заметнее.
- **Фонарик:** светлый круг вокруг курсора, остальной экран затемнён.
- **Пробел — мышь и правка рисунков:** пока держите пробел, нарисованное можно перетаскивать, а стрелкам, линиям и фигурам менять форму за точки. Клик мимо рисунков уходит в программу под ним.
- **Скриншот области** вместе с рисунками. Сохраняется в PNG и сразу копируется в буфер обмена.
- **Длинный скриншот:** программа сама прокручивает окно и склеивает кадры, подходит для страниц, лент и чатов.
- **Лента снимков** внизу экрана: сохранённые рисунки можно вернуть на экран, там же все скриншоты.
- **Горячие клавиши работают везде**, даже когда ScreenPen скрыт.
- **Значок в трее**, уведомления в углу экрана, настройки в одном текстовом файле.

## Требования и запуск

- Windows 10 или 11, ничего ставить не нужно. Windows 7 и 8 — после установки .NET Framework 4.8 (не проверялось).
- Запустите `ScreenPen.exe`. Программа появится в трее у часов, в углу будет подсказка.
- Повторный запуск не создаёт вторую копию.

## Все клавиши и действия

### Работают всегда, из любой программы

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+D` | Открыть / скрыть рисование. Во время длинного скриншота — остановить его |
| `Ctrl+Alt+S` | Скриншот области |
| `Ctrl+Alt+L` | Длинный скриншот с прокруткой |

### Режим рисования

| Клавиша | Действие |
|---|---|
| `1` | Кисть |
| `2` | Стрелка |
| `3` | Линия |
| `4` | Прямоугольник |
| `5` | Овал |
| `6` | Текст |
| `C` | Палитра цветов |
| `[` / `]` | Тоньше / толще |
| `Ctrl+Z` или `Backspace` | Отменить последнее |
| `Delete` | Очистить всё (отменяется `Ctrl+Z`) |
| `H` | Скрыть / показать рисунки |
| `D` | Затемнить экран (вкл / выкл) |
| `F` | Фонарик (вкл / выкл) |
| держать `Shift` | Фонарик, пока клавиша зажата |
| держать `Пробел` | Обычная мышь: двигать рисунки и менять их форму, клик мимо рисунков — в программу под ним |
| `S` | Скриншот области |
| `L` | Длинный скриншот |
| `G` | Лента снимков (открыть / закрыть) |
| `Ctrl+S` | Сохранить текущий рисунок как снимок |
| `Esc` | Закрыть ленту, если открыта, иначе скрыть рисование |

Цифры работают и на цифровой клавиатуре. Рисунок не пропадает при скрытии: он будет на месте при следующем открытии.

### Кнопки панели (сверху вниз)

Панель можно перетаскивать за полоску сверху.

| Кнопка | Действие |
|---|---|
| Кисть, стрелка, линия, прямоугольник, овал, `T` | Инструменты `1`–`6` |
| Цветной кружок | Палитра цветов. Открывается сбоку от панели, где есть место |
| Точка | Толщина: каждый клик — следующий размер |
| Луна | Затемнение |
| Круг в круге | Фонарик |
| Камера | Скриншот области |
| Лист со стрелкой | Длинный скриншот |
| Плёнка | Лента снимков |
| Глаз | Скрыть / показать рисунки. Подсвечен синим, пока рисунки скрыты |
| Стрелка назад | Отменить |
| Корзина | Очистить всё (отменяется `Ctrl+Z`) |
| `×` | Скрыть рисование |

### Текст

| Действие | Как |
|---|---|
| Начать | Инструмент «Текст» (`6`), клик в нужном месте |
| Готово | `Enter` или выбор другого инструмента |
| Готово и сразу новая надпись | Клик в другом месте |
| Отменить | `Esc` |

### Пробел: двигать и править рисунки

| Действие | Как |
|---|---|
| Включить | Держать `Пробел`. Панель станет полупрозрачной, курсор — обычным |
| Передвинуть рисунок | Навести на него (курсор — крестик со стрелками) и перетащить. Работает для штрихов кисти, фигур и текста |
| Изменить форму | Тянуть точку: у стрелки и линии — концы, у прямоугольника и овала — углы |
| Кликнуть в программу | Клик мимо рисунков |
| Отменить перемещение | `Ctrl+Z` |
| Выключить | Отпустить `Пробел` |

### Выделение для скриншота

| Действие | Как |
|---|---|
| Выделить область | Протянуть мышью. Рядом с рамкой виден размер в пикселях |
| Весь монитор | Клик без протягивания или `Enter` |
| Отмена | `Esc` или правая кнопка мыши |

### Длинный скриншот

| Действие | Как |
|---|---|
| Выбрать окно | Клик по нему: программа сама найдёт прокручиваемую часть. `Enter` — окно под курсором |
| Выбрать область | Протянуть рамку |
| Остановить раньше конца | `Esc` (или `Ctrl+Alt+D`) |
| Отмена до начала | `Esc` или правая кнопка мыши |

### Лента снимков

| Действие | Как |
|---|---|
| Переключить вкладку | «Снимки» / «Скриншоты» вверху ленты |
| Сохранить рисунок | Плитка `+` или `Ctrl+S` |
| Вернуть рисунок на экран | Клик по снимку |
| Копировать скриншот | Клик по скриншоту |
| Удалить | `×` в углу плитки (в Корзину Windows) |
| Ещё действия | Правая кнопка по плитке (список ниже) |
| Прокрутка ленты | Колесо мыши |
| Открыть папку | Кнопка с папкой |
| Закрыть ленту | `×` справа вверху, `G` или `Esc` |

Меню по правой кнопке:
- **снимок:** «Вернуть на экран», «Копировать картинку», «Сохранить картинку как…», «Удалить (в Корзину)»;
- **скриншот:** «Копировать», «Открыть», «Показать в папке», «Удалить (в Корзину)».

### Значок в трее

| Действие | Как |
|---|---|
| Открыть / скрыть рисование | Левый клик |
| Меню | Правый клик: «Рисовать», «Скриншот области», «Длинный скриншот», «Открыть папку скриншотов», «Очистить рисунок», «Выход» |

## Подробнее о функциях

**Скриншот области.** Экран «замирает», и выделяется ровно то, что вы видите. На скриншот попадают рисунки, затемнение и фонарик, но не панель и не лента. Готовый PNG сохраняется в папку скриншотов и копируется в буфер обмена, в углу появляется карточка. Клик по карточке открывает папку с файлом.

**Длинный скриншот.** Программа ставит курсор в область и крутит колесо, после каждого шага делает снимок и находит, на сколько сдвинулось содержимое. Закреплённые шапки и подвалы сайтов, боковые меню, догружающиеся картинки и GIF она учитывает. Останавливается сама в конце страницы, на пределе 20 000 px или по `Esc`. Учтите:
- прокрутка идёт от того места, которое сейчас видно; для всей страницы сначала прокрутите её в начало;
- рисунки ScreenPen в длинный скриншот не попадают;
- видео и анимация на странице могут дать шов или картинку, склеенную из двух состояний;
- каждый шаг записывается в `ScreenPen.log` — пригодится, если что-то пошло не так.

**Снимки.** Снимок хранит сам рисунок (штрихи, фигуры, текст) и картинку экрана. Вернув снимок на экран, его можно дорисовывать и отменять действия. Снимки не пропадают после выхода из программы.

**Пробел.** Пока он зажат, нарисованное можно перетаскивать: за рисунок можно ухватиться в пределах примерно 8 px от линии. У стрелок и линий на концах, а у прямоугольников и овалов по углам появляются белые точки, их можно тянуть. Клики мимо рисунков уходят в программы под ними. После клика по другой программе клавиши ScreenPen снова заработают после первого клика или рисования на экране.

## Настройки — `ScreenPen.ini`

Лежит рядом с exe. Изменения применяются сразу, перезапуск не нужен.
В архиве из релиза он уже есть. Если собираете из исходников, скопируйте `ScreenPen.ini.example` под именем `ScreenPen.ini`.

```ini
; скриншоты (PNG)
ScreenshotFolder=D:\ScreenPen\Screenshots
; снимки рисунков
SnapshotFolder=D:\ScreenPen\Snapshots
```

Комментарий — строка, которая начинается с `;`. В одной строке с путём комментарий писать нельзя.
Если файла нет или строки с путём нет, используется папка `Изображения\ScreenPen`.

## Файлы

| Файл | Что это |
|---|---|
| `ScreenPen.exe` | Программа. В репозитории её нет: скачайте из релиза или соберите `build.cmd` |

| `tests\` | Тесты |

## Сборка из исходников

Запустите `build.cmd`. Он использует компилятор C#, встроенный в Windows, ставить ничего не нужно.
Перед сборкой закройте запущенный ScreenPen (меню в трее → «Выход»).

## Тесты

Запустите `test.cmd`. В конце должно быть `TESTS PASSED`.

- **Фигуры и отмена** (`tests\ShapeTest.cs`): распознавание стрелок, линий и фигур, в том числе восстановленных из снимка; захват мышью около контура; отмена «Очистить всё».
- **Склейка длинных скриншотов** (`tests\StitchTest.cs`): искусственные страницы с закреплёнными шапкой и подвалом, боковым меню, ползунком прокрутки, пустыми промежутками, а также «живые» страницы с догружающимися картинками и GIF. Страницы нарезаются на кадры, склеиваются обратно и сравниваются с оригиналом пиксель в пиксель.

Больше страниц для склейки: `set STITCH_SEEDS=1-40` перед запуском.

## Исходный код

| Файл в `src\` | Что внутри |
|---|---|
| `App.cs` | Запуск, значок в трее, меню, уведомления |
| `OverlayWindow.cs` | Прозрачное окно поверх экрана: рисование, панель, скриншоты, клавиши |
| `OverlayWindow.Snapshots.cs` | Лента снимков и скриншотов |
| `OverlayWindow.PassThrough.cs` | Режим пробела: перемещение рисунков, точки для изменения формы, клики сквозь окно |
| `ScrollCapture.cs` | Длинный скриншот: прокрутка, поиск сдвига между кадрами, склейка |
| `Toast.cs` | Карточки-уведомления в углу экрана |
| `Settings.cs` | Чтение `ScreenPen.ini` |
| `Icons.cs` | Иконки кнопок и значок в трее |
| `Log.cs` | Журнал `ScreenPen.log` |
